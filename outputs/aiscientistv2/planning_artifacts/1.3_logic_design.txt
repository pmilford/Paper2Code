[Logic Analysis]
- ['dataset_loader.py', 'DatasetLoader class: Responsible for loading data using the Hugging Face datasets library, performing preprocessing, splitting the data (e.g., train/test splits) for the different experiments (synthetic arithmetic, label noise calibration, and pest detection). Imports numpy for data handling and supports augmentation if needed for pest detection. This file is used by main.py and experiment_manager.py.']
- ['model.py', 'Model class: Defines the network architectures. Contains implementations for an LSTM-based model (with compositional regularization) and a ResNet-18 based model for image experiments. Imports torch.nn and torch.nn.functional for building the models. This file is imported by trainer.py and evaluation.py.']
- ['trainer.py', 'Trainer class: Implements the training loop for a given model and dataset. Computes loss (including additional regularization terms for the compositional experiment), performs backpropagation, updates parameters using optimizers, and logs training progress. Uses torch.optim and manages checkpoints. This module is used by main.py and experiment_manager.py.']
- ['evaluation.py', 'Evaluation class: Provides methods to evaluate the model on validation/test sets. Computes performance metrics such as mean square error, prediction accuracy (with a tolerance), Expected Calibration Error (ECE), and Environmental Robustness Score (ERS). Also responsible for generating plots using Matplotlib. Imported by main.py and experiment_manager.py.']
- ['experiment_manager.py', 'ExperimentManager class: Coordinates the overall experiment lifecycle including multiple stages (preliminary investigation, hyperparameter tuning, research agenda execution, and ablation studies). It manages multiple experimental runs (nodes) for tree search, replication of experiments with different random seeds, and aggregation of results. Calls DatasetLoader, Trainer, Evaluation and utilizes utils.py functions for logging and configuration. Serves as the central controller in main.py.']
- ['utils.py', 'Utility module: Contains shared functions such as configuration management, logging setup, random seed initialization, checkpoint save/load helpers, and common plot functions. These utilities are shared among dataset_loader.py, trainer.py, evaluation.py, and experiment_manager.py.']
- ['main.py', 'Main entry point: Reads configuration parameters, instantiates the ExperimentManager, and triggers the pipeline execution. It coordinates the process flow by calling into DatasetLoader, Model, Trainer, Evaluation, and ExperimentManager classes.']
